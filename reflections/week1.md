Before this module I would have described software simply as a set of instructions or programs that allow a computer to perform tasks. Software is intangible and is present in programming languages as code. I would describe software as the brain of the computer because it tells the computer its purpose and how to function. Software engineering is the process of creating, managing, testing and maintaining software applications and systems.

Software that I find works well is Youtube. I find it easy to use and reliable for its intended purpose. This suggests that the developers have focused on making the software functional and user-friendly, as well as constantly maintaining and updating it.

In contrast, I find the Boots app frustrating because it is frequently unavailable due to maintenance, but the same issues seem to persist afterwards. The developers could improve this by testing updates more thoroughly before releasing them and investigating the underlying causes of the problems rather than repeatedly taking the app offline.
